# CapSept Accessibility Statement

**Last reviewed: 7 November 2026**

CapSept is built for people preparing for the TEF Canada and TCF Canada French tests, including
older learners who use larger text. Accessibility is checked before each release, not added later.

## Supported features

| Feature | How CapSept supports it |
| --- | --- |
| VoiceOver | Every control is labelled. Answer options say their letter, position and state. Each skill's level is read as one sentence with the exam-day outlook. Charts have audio graphs. Clips announce when they finish, timed tasks announce five minutes and one minute left, and the feed has a "Next card" action. |
| Voice Control | Standard controls throughout. Answer options respond to their letter ("A", "option A"). A visible Next button replaces swiping. |
| Larger Text | All text uses Dynamic Type. Layouts stack into columns at accessibility sizes; documents scroll inside their card rather than truncating. Widgets show only the countdown at the largest sizes. |
| Dark Interface | Dark and light appearances are both designed. |
| Differentiate Without Color Alone | Correct and wrong answers carry a glyph and a word. Levels carry a bar, a target line, a written level and a glyph. Key phrases are underlined as well as emphasised. |
| Sufficient Contrast | Every text colour meets WCAG AA in tests, with stronger colours when Increase Contrast is on. |
| Reduced Motion | All animation goes through one setting-aware path; with Reduce Motion it is removed. |
| Captions | Every listening clip has a transcript, shown after answering, or during playback with **Show captions while clips play** in Settings. |

The interface is available in English and French.

## Turning features on

Use iOS Settings > Accessibility. CapSept follows the system settings automatically; the only
CapSept setting is captions during playback (Plan > Settings).

## Feedback

Report a barrier at <https://github.com/arieltyson/CapSept-accessibility/issues>. Known gaps are
listed in [Known issues](https://arieltyson.github.io/CapSept-accessibility/known-issues/).
