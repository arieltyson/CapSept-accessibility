# CapSept Accessibility Standards & Tracking

Welcome to the public accessibility repository for `CapSept`. We believe technology should be usable by everyone, regardless of ability.
The statement is published at <https://arieltyson.github.io/CapSept-accessibility/>.

## Why is this on GitHub?
Accessibility is an ongoing process, not a one-time checklist. This repository serves as our public ledger for:
1. **Compliance Tracking:** Documenting our adherence to Apple's Accessibility Nutrition Labels and WCAG standards.
2. **Known Limitations:** Openly acknowledging where we fall short in `KNOWN_ISSUES.md` so users know what to expect.
3. **Community Feedback:** Providing a direct line for users who rely on assistive technologies to request fixes.

## What CapSept supports
VoiceOver, Voice Control, Larger Text up to the largest accessibility size, Dark Interface, Differentiate Without Color Alone, Sufficient Contrast and Reduced Motion across every common task. Listening transcripts are time-synchronised and can be shown during practice for users who need them.

## Reporting an Accessibility Barrier
If you encounter a barrier while using `CapSept` (e.g., unlabeled VoiceOver elements, poor contrast, motion sensitivity triggers):
1. Open a new **Issue** in this repository.
2. Describe the barrier, the assistive technology you are using (e.g., VoiceOver, Switch Control), and your device.
3. Accessibility issues are fixed before new features in each release.
